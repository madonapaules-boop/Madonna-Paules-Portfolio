# Owner assets

From **Owner dashboard → Profile**, upload the profile image using **Upload image**. Accepted formats are PNG, JPEG, and WebP up to 4 MB. Upload the resume using **Upload CV (PDF)**; PDF files are accepted up to 8 MB.

After an upload completes, select **Save profile** to publish the new image or CV link. Both files are stored through the project storage service and their public references are saved with the portfolio profile.
